Use the Pono tools to answer: where do my projects stand?

Call `list_projects`, then answer in the person's language: the verdicts first (what needs a
decision), then each project with its state and when it was last read. Name facts, not guesses;
if a reading is stale, say so. Offer to open a project with `get_project` when one needs attention.
